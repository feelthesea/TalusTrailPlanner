# 🏔️ Talus - Trail Roadbook Generator (越野跑路书与轨迹分析)

[简体中文](README.md) | [English](README_EN.md)

**Talus** 是一款为越野跑爱好者、教练和赛事总监设计的**交互式越野跑路书与配速计划工具**。

导入 GPX / KML / KMZ 路线后，你可以在高程剖面上标出 CP 点，填一个目标完赛时间让系统自动分配每段用时，再按需要锁定、微调，最后导出适配手机屏幕比例的高清路书图片。地图、坡度分布和实战技术要点帮你进一步了解赛道。

> [!NOTE]
> 👤 **开发者**：本网页由 **Laurent L** 通过 Vibe Coding 协作开发。  
> 🔒 **100% 隐私安全**：纯前端应用。轨迹解析、计算、图片导出和自动保存全部在你的浏览器本地完成，**不会上传任何轨迹数据**。

## ✨ 核心特性

- 🧭 **步骤引导**：页面顶部的步骤条（上传轨迹 → 设置 CP → 目标时间 → 微调分段 → 导出路书）会根据你的数据自动打勾，并提示下一步该做什么。每一步都可以随时点击跳转，不强制顺序。
- 📂 **拖放上传**：把 GPX / KML / KMZ 轨迹或 JSON 配置文件拖到页面任意位置即可载入；没有现成文件时，可以先点「用示例赛道试一试」。
- 📍 **CP 点设置**：GPX 中的航点会自动变成 CP（可撤销）；在剖面图上**双击**即可在该位置添加 CP；距离、名称都能在计划表里直接修改。
- 🎯 **目标时间自动分配**：填一个目标完赛时间，系统按每段的「努力距离」（距离 km + 爬升 m ÷ 100）把用时分配到各段。手动输入的分段会被锁定 🔒，其余分段自动重新分配，总时间始终等于目标。
- 📋 **比赛计划表**：每个 CP 一行，集中显示距离、分段剖面、爬升 / 下降、分段用时、停留时间、预计抵达时刻（含昼夜图标）和每段的碳水 / 水 / 钠需求，所有数值可以直接在表里修改。手机上会自动变成卡片布局。
- 🍌 **补给需求**：按每段的预计用时（不含停留）算出这一段需要多少碳水、水和钠，默认碳水 40–90 g/h、水 450–750 ml/h、钠 300–600 mg/h，可以改成自己的区间或单个数值，表格上方同时显示全程合计。
- 🌙 **真实日出日落与夜间路段**：按赛道位置和比赛日期计算日出日落，比赛当地时区自动判断（国内统一 UTC+8，出国比赛可手动选择）。预计抵达旁的图标表示白天、日落前后、夜间或日出前后，剖面图上用阴影标出需要头灯的夜间路段。
- ⛰️ **爬坡列表与高海拔提示**：按地形自动识别主要爬坡（位置、所在赛段、长度、爬升、平均坡度、最陡 200 m、坡顶海拔），点击可在剖面图和地图上定位；赛道超过 2500 m 时显示高海拔路段、预计用时和高反提示，剖面图上画出 2500 m / 3500 m 参考线。
- 💾 **本地自动保存**：轨迹和所有设置自动保存在这个浏览器里，下次打开直接继续；「导入 ▾ → 新建路书」可以清空重来。
- 📈 **交互式路书剖面图**：鼠标或手指在剖面上滑动，显示距离、海拔和坡度，地图上的定位点同步移动；点击表格行或剖面分段，剖面、地图和表格会同时高亮该段。
- 🎨 **三种着色**：经典路书柱条、按坡度渐变、按海拔渐变。
- ⚡ **两种爬升算法**：平滑（4 m 滞后阈值，过滤 GPS / 气压计噪点，更接近手表和官方数据）与原始数据。
- 🗺️ **多图源地图**：OpenStreetMap、OSM 人道主义风格、OpenTopoMap（等高线地形图）、CyclOSM，以及天地图（路网 / 卫星 / 地形）和高德（混合 / 路网，自动做 WGS-84 → GCJ-02 纠偏），可以随时切换。导入轨迹时会按所在地区自动切换：国内用天地图路网，国外用 OpenStreetMap。勾选「徒步路线」可在底图上叠加 [Waymarked Trails](https://hiking.waymarkedtrails.org) 标注的徒步路线（高德底图下不可用，因为坐标系不同对不齐）。选用天地图时如果加载失败，会自动切换到备用图源。
- 📐 **6 级坡度分布与技术要点**：上坡和下坡各分 6 级（≤5%、5–10%、10–15%、15–25%、25–35%、>35%），附带步频、用杖、重心和缓冲等实战建议。
- 🖌️ **CP 视觉配置**：9 种补给站类型图标、垂直指示线颜色与粗细、剖面图内 6 个位置的自定义标注（可旋转）、多行备注。
- 📱 **壁纸级图片导出**：画布比例可选自适应、19.5:9（iPhone 等）、20:9（主流安卓手机），分辨率 1× / 2× / 3×。导出图片内嵌网页字体，与屏幕上看到的一致。
- 🖨️ **A4 打印版计划表**：一页纸包含路书剖面、计划表（含补给需求和昼夜）以及爬坡列表，可直接打印或在打印对话框里另存为 PDF。
- 💾 **JSON 配置导入 / 导出**：保存 CP、目标时间、锁定的分段和所有视觉设置，下次导入即可继续编辑。

## 📖 使用步骤

页面从上到下就是操作顺序：**路书剖面 → 比赛计划 → 地图与坡度分析**。顶部步骤条会一直提示你当前在哪一步。

### 第一步：上传轨迹
1. 把 `.gpx`、`.kml` 或 `.kmz` 文件**拖到页面上**，或点击剖面区域里的「选择文件」（也可以用顶栏的「导入 ▾ → 上传轨迹文件」）。
2. 载入后会自动：
   - 绘制高程剖面，并把终点设在轨迹终点；
   - 把 GPX 中的航点设为 CP（提示框里可以一键撤销）；
   - 如果轨迹带有时间信息，用第一个点的时间作为出发时间；
   - 按轨迹所在地区切换地图：国内用天地图路网，国外用 OpenStreetMap。如果当前图源已经适合该地区（比如国内选了卫星图、国外选了 OpenTopoMap），则保留你的选择。
3. 想先看看效果？点击「用示例赛道试一试」，载入一条虚构的约 42 km 示例赛道。

### 第二步：设置 CP 点
- **在剖面图上双击**：在该位置添加一个 CP。
- **「添加 CP」按钮**：在当前选中的 CP 和下一个 CP 中间添加一个。
- **在比赛计划表里直接修改**名称和距起点距离，表格会自动按距离重新排序。
- 点击行右侧的 **配置按钮**（或双击该行）打开详细设置：补给站类型图标、垂直指示线、剖面图内标注、备注，以及「用于分段统计点」（是否在剖面图底部划分子赛段）。
- 删除 CP 后，提示框里同样可以撤销。

### 第三步：设定目标时间
1. 在比赛计划表上方设置 **出发时间** 和 **目标完赛** 时间。目标时间支持 `14:00`、`13h30`，或直接写 `14`（表示 14 小时）。出发时间按比赛当地时间填写；旁边的 **时区** 默认按赛道位置自动判断，旁边显示当天的日出日落时间，出国比赛时请核对一下。
2. 系统会按每段的努力距离（距离 km + 爬升 m ÷ 100）自动分配各段用时，表格中标注「按目标分配」，剖面图上同步显示各 CP 的到达时间。
3. 表格上方的提示会告诉你：是否刚好达到目标，或者锁定的分段和停留比目标多出多少。

> 不设目标也可以：没填用时的分段会按默认配速估算（每公里 12 分钟 + 每 100 m 爬升 10 分钟），并标上 `≈`。估算值只显示在表格里，不会画到导出的路书上。

### 第四步：微调分段（可选）
- **锁定某段用时**：直接在「分段用时」里输入，例如 `1:45`、`1h45`、`105`（分钟）。该段会被锁定 🔒，其余未锁定的分段自动重新分配。点击锁图标可以改回自动分配。
- **停留时间**：在「停留」列填写每个补给站的停留分钟数。停留会计入总时间，预计抵达时刻不包含本站停留，表格里会另外显示离站时间。
- 预计抵达时刻旁的图标表示白天 ☀️、日落前后 🌅、夜间 🌙 或日出前后 🌄，按 CP 所在位置和抵达时刻的真实太阳高度计算；剖面图上的阴影是计划中需要头灯的夜间路段（浅色为晨昏时段）。
- **补给需求**：「每小时补给」一行可以填碳水（g）、水（ml）、钠（mg）每小时的需求，写区间（`40-90`）或单个数值（`60`），留空则不显示。表格最后一列显示每段需要的量，按该段预计用时计算，不含补给站停留时间。参考依据：碳水在超过 2 小时的比赛里最多约 90 g/h，6 小时以上的超马常见 30–50 g/h；水 450–750 ml/h；钠 300–600 mg/h（约每升水 500–700 mg），见 [ISSN 超马营养立场声明（Tiller 等, 2019）](https://pmc.ncbi.nlm.nih.gov/articles/PMC6839090/)。

### 第五步：导出路书
1. 在剖面图标题栏选择 **画布** 比例（会同时改变屏幕预览）：
   - **自适应**：紧凑，无白边；
   - **19.5:9**：适配 iPhone 等全面屏手机；
   - **20:9**：适配小米、华为、OPPO、vivo 等主流安卓手机。
2. 需要的话，在同一栏调整 **着色**、**爬升** 算法和 **字号**（比赛名、CP 名、海拔、用时、备注、分段信息、底部距离可分别设置）。
3. 点击顶栏的 **「导出 ▾」**，选择 **标准 1×**、**高清 2×**（推荐）或 **超清 3×** 下载 PNG。
4. 选择 **「打印计划表」** 打印 A4 计划表（也可以在打印对话框里存成 PDF），在浏览器里直接按 Ctrl+P 也会打印这份计划表。
5. 选择 **「导出路书配置」** 保存 JSON，下次用「导入 ▾ → 导入路书配置」恢复。JSON 里不包含轨迹本身，需要另外上传同一条轨迹。在同一个浏览器里不用导出：轨迹和设置会自动保存，下次打开直接恢复。

### 参考：爬坡与海拔
页面最下方的 **爬坡与海拔** 按地形识别主要爬坡，和按 CP 切分的计划表互为补充：计划表告诉你两个 CP 之间一共爬多少，爬坡列表告诉你真正难的坡在哪里、有多长多陡、落在哪个赛段。点击一行可以在剖面图和地图上定位。赛道超过 2500 m 时，这里还会列出高海拔路段和预计在高海拔停留的时间。

## 🗂️ 配置文件格式

「导入 ▾ → 下载配置模板」可以下载一个示例。主要字段：

```json
{
  "raceName": "Talus 经典越野跑 100K",
  "startTime": "2026-08-28T06:00",
  "utcOffset": "auto",
  "targetTime": "14:00",
  "carbsPerHour": "40-90",
  "waterPerHour": "450-750",
  "sodiumPerHour": "300-600",
  "elevationMode": "smooth",
  "colorMode": "classic",
  "exportRatio": "20-9",
  "checkpoints": [
    { "name": "起点", "distance": 0, "segmentTime": "0:00", "icon": "start" },
    { "name": "CP1", "distance": 15, "segmentTime": "1:45", "stopDuration": 5, "icon": "classic" },
    { "name": "CP2", "distance": 52, "segmentTime": "", "stopDuration": 15, "icon": "dropbag" },
    { "name": "终点", "distance": 100, "segmentTime": "", "icon": "finish" }
  ]
}
```

- `segmentTime` 留空表示按目标时间自动分配，填写则表示锁定该段。
- `stopDuration` 为停留分钟数。
- `utcOffset` 为比赛当地时区：`auto` 按赛道位置自动判断，或写成 `+02:00` 这样的固定值。
- `carbsPerHour` / `waterPerHour` / `sodiumPerHour` 为每小时的碳水（g）、水（ml）、钠（mg）需求，可写区间或单个数值，空字符串表示不显示。
- 只有 `arrivalTime`（累计抵达时间）的旧版配置文件仍然可以导入，会自动换算成分段用时。

## 🚀 在线体验与本地运行

### 1. 在线使用
直接访问在线部署地址：  
**🔗 [https://feelthesea.github.io/TalusTrailPlanner/](https://feelthesea.github.io/TalusTrailPlanner/)**

### 2. 本地运行
本项目是纯静态网页，没有构建步骤。由于示例赛道和导出字体需要通过 HTTP 读取，请用本地服务器打开，而不是直接双击 `index.html`。

```bash
# 1. 克隆代码到本地
git clone https://github.com/feelthesea/TalusTrailPlanner.git

# 2. 进入项目目录
cd TalusTrailPlanner

# 3. 启动一个本地静态网页服务器（例如 Python 内置服务器）
python -m http.server 8080

# 4. 在浏览器中打开：http://localhost:8080
```

### 3. 代码结构
| 文件 | 作用 |
|---|---|
| `index.html` / `style.css` | 页面结构、样式与线条图标 |
| `js/app.js` | 状态管理、中英文切换、步骤条、比赛计划表、导入导出 |
| `js/gpx-parser.js` | GPX / KML / KMZ 解析与距离、坡度计算 |
| `js/trail-math.js` | 配色、坐标纠偏、爬升算法 |
| `js/trail-analysis.js` | 坡度分布、分段统计、目标时间分配、爬坡识别、高海拔路段 |
| `js/sun.js` | 太阳高度、日出日落、比赛时区判断 |
| `js/storage.js` | 本地自动保存（localStorage + IndexedDB） |
| `js/profile.js` | SVG 路书剖面图与交互 |
| `js/trail-map.js` | Leaflet 地图与图源 |
| `js/export.js` | PNG 导出（内嵌字体） |
| `fonts/` | 本地托管的网页字体 |
| `samples/sample-trail.gpx` | 示例赛道（虚构的演示轨迹） |
