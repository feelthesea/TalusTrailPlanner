# 🏔️ Talus - Trail Roadbook Generator (越野跑路书与轨迹分析)

[简体中文](README.md) | [English](README_EN.md)

**Talus** 是一款专为越野跑爱好者和赛事总监设计的**高颜值、全交互式越野跑路书与高程图生成工具**。

你可以直接导入 GPX / KML / KMZ 路线文件，进行交互式地图与高程剖面分析、6 级坡度分布与技术指导查看、多模式分段统计，自定义添加补给站（CP点），动态编辑抵达时间与备注，并一键导出完美适配现代手机屏幕比例的高清路书图片，作为比赛期间的手机壁纸或打印使用。

> [!NOTE]
> 👤 **开发者**：本网页由 **Laurent L** 通过 Vibe Coding 协作开发。
> 🔒 **100% 隐私安全**：本工具为纯前端应用，所有 GPX / KML / KMZ 解析、计算与图片导出完全在你的浏览器本地进行，**没有任何网络上传**，绝对保障你的路线隐私。

## ✨ 核心特性

- ☀️ **通用高对比度配色系统 (Universal Palette)**：精心设计的户外高对比度配色，既保证了烈日暴晒下的清晰可读，也兼顾了夜间户外暗光环境下的视觉舒适度。
- ⚡ **累计爬升下降算法切换**：支持「原始数据」与「平滑滤波 (4m 滞后阈值)」两种计算模式，有效过滤气压计/GPS 微噪点，与主流户外手表及赛事官方数据精准对齐。
- 🗺️ **交互式轨迹地图 (Interactive Map)**：集成天地图（路网/卫星/地形）、高德地图（混合/路网）、OpenStreetMap、OpenTopoMap、CyclOSM 等多种户外图源，支持按坡度/海拔渐变着色，高德图层自动进行 WGS-84 转 GCJ-02 坐标纠偏。
- 📈 **实时高程与坡度交互剖面 (Elevation Profile & Crosshair)**：基于 Canvas Path2D 与屏幕自适应 LOD 降采样渲染，标注最高点/最低点与关键爬升段，鼠标或触控拖动时与地图位置实时十字线联动。
- 📐 **6 级坡度分布与实战技术要点 (Gradient Distribution & Tech Tips)**：将路线精确拆解为平缓、缓坡、中坡、陡坡、很陡、极陡 6 级上坡与 6 级下坡，并提供步频、杖法、重心与缓冲等实战技术指导。
- 📋 **多模式分段统计 (Segment Statistics)**：支持「📍 检查点分段」、「📈 坡度变化自动分段」、「📏 1 km 固定分段」及「📏 5 km 固定分段」，点击任意分段可在地图和高程图上高亮定位。
- ⏱️ **抵达用时与区间用时自动计算**：只需输入抵达每个 CP 点的**总累计时间**，系统将自动计算出相邻 CP 点之间的**区间分段用时**。
- 📍 **瑞士峡谷风格垂直文字 (Rotated CP Names)**：CP 点名称贴着垂直轴线纵向显示，彻底避免了横向文字在密集检查点时的重叠遮挡，美观规整。
- 📊 **三行式高拟真分段信息框**：底部子赛段的距离、爬升（绿色 `▲`）和下降（红色 `▼`）分三行清晰展现，直观易读。
- 🎭 **多图标叠加组合 (Multi-Icons)**：每个检查点支持配置多种功能图标（如水站 `💧` + 热食 `🍽️` + 医疗 `🏥`），拥有 12 种精美矢量图标。
- 📱 **多比例壁纸级导出**：支持默认自适应（无白边）、19.5:9横屏（适配 iPhone 17/16 全面屏手机壁纸）、20:9横屏（适配小米、华为 Pura 及主流安卓全面屏手机），支持 1× / 2× / 3× 高清分辨率导出。
- 📥 **一键导入/导出 JSON 配置**：支持将所有打点和视觉微调数据保存为本地 JSON 文件，方便下次继续编辑，同时提供一键下载模板功能。

## 📖 详细使用步骤

1. **导入路线**：点击 **“📂 上传轨迹 (GPX/KML/KMZ)”** 按钮，选择你的越野跑路线文件。系统会自动绘制高程剖面路书、交互式地图、坡度分布与分段数据。
2. **切换算法与地图**：
   - 在顶部工具栏切换 **“爬升计算：平滑(4m) / 原始数据”**。
   - 在地图卡片切换天地图、高德地图或地形图，并切换按坡度或按海拔着色。
3. **查看坡度分布与分段**：
   - 在 **“坡度分布与技术要点”** 中查看各坡度等级占比及步法建议。
   - 在 **“多模式分段统计”** 中切换检查点/坡度/1km/5km分段，点击行高亮地图对应路段。
4. **编辑 CP 点表**：
   - 在 CP 列表中编辑每个补给站的名称、累计距离（km）和备注信息。
   - 在 **“抵达cp点总用时”** 列输入累计用时（例如 `4:35`），系统自动计算区间耗时。
5. **视觉微调与导出**：
   - 点击表格或下方卡片微调该 CP 点的图标、指示线与文字标注。
   - 在顶部的 **“导出比例”** 选择适合手机屏幕的比例，点击 **“🖼️ 下载图片 ▾”** 导出高清 PNG 路书！
