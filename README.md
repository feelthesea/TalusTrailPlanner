# 🏔️ Talus - Trail Roadbook Generator (越野跑路书与轨迹分析)

[简体中文](README.md) | [English](README_EN.md)

**Talus** 是一款专为越野跑爱好者、教练和赛事总监设计的**高颜值、全交互式越野跑路书与高程剖面分析工具**。

你可以直接导入 GPX / KML / KMZ 路线文件，进行交互式地图与高程剖面探索、6 级坡度分布与实战技术指导查看、多模式分段统计，在浮动弹窗中便捷配置补给站（CP点）图标、垂直指示线与自定义文字标注，并一键导出完美适配现代手机屏幕比例的高清壁纸级路书图片。

> [!NOTE]
> 👤 **开发者**：本网页由 **Laurent L** 通过 Vibe Coding 协作开发。  
> 🔒 **100% 隐私安全**：本工具为纯前端应用，所有 GPX / KML / KMZ 解析、计算与图片导出完全在你的浏览器本地进行，**绝不上传任何轨迹数据至服务器**，保障你的路线隐私。

---

## ✨ 核心特性

- 📈 **全能统一交互路书高程图 (Unified Profile)**：融合高保真矢量路书编辑与 60fps 实时探索，鼠标或触控拖动时即时显示十字准线与详细数值，并与地图定位点平滑联动。
- 🎨 **三模式着色自由切换**：支持「经典路书柱条 (Classic Sisyf Bars)」、「按坡度平滑渐变 (Grade Gradient)」与「按海拔连续渐变 (Elevation Gradient)」。
- 🗺️ **交互式轨迹地图 (Interactive Map)**：集成天地图（路网/卫星/地形）、高德地图（混合/路网）、OpenStreetMap、OpenTopoMap、CyclOSM 等多种户外图源，高德图层自动进行 WGS-84 转 GCJ-02 坐标纠偏。
- ⚡ **累计爬升下降算法切换**：支持「原始数据」与「平滑滤波 (4m 滞后阈值)」两种计算模式，有效过滤气压计/GPS 微噪点，与主流户外手表及赛事官方数据精准对齐。
- 📐 **6 级坡度分布与实战技术要点 (Gradient Distribution & Tech Tips)**：将路线精确拆解为平缓(≤5%)、缓坡(5-10%)、中坡(10-15%)、陡坡(15-25%)、很陡(25-35%)、极陡(>35%) 6 级上坡与 6 级下坡，并提供步频、杖法、重心与缓冲等实战技术指导。
- 📋 **多模式分段统计 (Segment Statistics)**：支持「📍 检查点分段」、「📈 坡度变化自动分段」、「📏 1 km 固定分段」及「📏 5 km 固定分段」，点击任意分段可在地图和高程图上高亮定位。
- 📍 **浮动式检查点视觉配置 (Floating Modal)**：点击表格行或「⚙️」设置按钮弹出半透明浮动面板，快捷配置 12 种补给站类型图标、垂直指示线颜色与粗细、内嵌文字标注（左3+右3，支持旋转横竖排）。
- 📊 **三行式高拟真分段信息框**：底部子赛段的距离、爬升（绿色 `▲`）和下降（红色 `▼`）分三行清晰展现，直观易读。
- 📱 **多比例壁纸级导出**：支持默认自适应（无白边）、19.5:9横屏（适配 iPhone 17/16 全面屏手机壁纸）、20:9横屏（适配小米、华为 Pura 及主流安卓全面屏手机），支持 1× / 2× / 3× 高清分辨率导出。
- 📥 **一键导入/导出 JSON 配置**：支持将所有打点和视觉微调数据保存为本地 JSON 文件，方便下次继续编辑，同时提供一键下载模板功能。

## 📖 详细使用步骤

### 第一步：导入路线轨迹文件 (Import GPX/KML/KMZ)
1. 点击顶部工具栏左侧的 **“📂 上传轨迹 (GPX/KML/KMZ)”** 按钮。
2. 选择你的越野跑路线文件（支持 `.gpx`、`.kml` 或包含航点的 `.kmz` 文件）。
3. 网页将全自动完成解析并在页面三大区域同步呈现：
   - **区域 1**：绘制完整的高程剖面图及默认起终点；
   - **区域 2**：地图自动定位并绘制着色轨迹线，右侧自动计算 8 项核心指标与 6 级坡度分布；
   - **区域 3**：自动生成 CP 点列表及检查点分段统计。

### 第二步：设置赛事基本信息与计算模式 (Configure Race Info)
1. 在顶部输入 **比赛名称**（例如 `UTMB 2026 100K`）。
2. 选择 **出发时间**（例如 `周五 18:00`），系统将据此推算各站点的通过时刻与星期。
3. 选择 **⚡ 爬升计算模式**：
   - **平滑 (4m)**（推荐）：过滤 GPS 噪点，更贴合实际路感；
   - **原始数据**：展示原始无滤波累计爬升。
4. 选择 **🎨 剖面着色模式**：可在「经典路书柱条」、「按坡度渐变」和「按海拔渐变」中随时切换。

### 第三步：添加与编辑 CP 检查点 / 补给站 (Add & Configure Checkpoints)
1. **添加新检查点**：点击区域 3 左侧的 **“＋ 添加 CP 点”** 按钮。
2. **快捷就地编辑**：
   - 在表格中直接修改 **CP 名称**；
   - 修改 **距起点 (km)** 距离数值，检查点将自动按距离重新排序并刷新剖面图；
   - 在 **“分段用时”** 输入该赛段预估用时（例如 `1:30`），或输入总抵达用时。
3. **打开详细视觉配置浮窗**：
   - 点击该行右侧的 **“⚙️”** 按钮（或双击该行）；
   - 在弹出的浮动面板中设置：
     - **补给站类型图标**：起点 🟢、终点 🏁、水源点 💧、普通补给 🍉、寄存包 🛍️、有人协助 🤝、山峰 🏔️、打卡点 🚩、危险 ⚡ 等；
     - **垂直指示辅助线**：自定义线条颜色与线宽 (px)；
     - **图表内嵌自定义标注**：在左/右、上/中/下 6 个位置添加文本（如配速提醒、收杖提醒、关门时间等），并可设置字号与横排/竖排旋转角度；
     - **停留时间 (分钟)**：设置进站补给休息时间；
   - 点击 **“✓ 保存并应用”**，所有配置立即在剖面图与地图上生效。

### 第四步：多维度轨迹分析与交互探索 (Interactive Analytics)
1. **实时十字线与地图联动**：在区域 1 的剖面图上滑动鼠标或手指触摸，浮窗实时展示当前距离、海拔及瞬时坡度，区域 2 的地图红色定位点同步沿轨迹滑动。
2. **多底图切换**：在地图右上角切换天地图（路网/卫星/地形）、高德地图（混合/路网）、OpenTopoMap、CyclOSM 等。
3. **坡度与技术指导**：查看 6 级上坡与下坡占比，阅读关于步幅、杖法与重心的实战技术建议。
4. **多模式分段统计**：在区域 3 右侧切换「📍 检查点」、「📈 坡度变化」、「📏 1 km」、「📏 5 km」，点击任意分段行可在地图与高程图上高亮定位该赛段。

### 第五步：字号微调与壁纸级图片导出 (Font Adjustments & PNG Export)
1. **字号独立微调**：在区域 1 右侧的「各元素字号大小设置」面板中，独立调整比赛名、CP名、爬升、用时、备注、分段、底部距离的像素字号。
2. **选择导出比例**：在顶部工具栏的「导出比例」下拉框中选择：
   - **默认自适应 (无白边)**：紧凑无缝；
   - **19.5:9横屏**：完美适配 iPhone 17/16/15 等 iOS 锁屏壁纸；
   - **20:9横屏**：完美适配小米、华为 Pura、OPPO、vivo 等主流安卓全面屏壁纸。
3. **下载高清图片**：点击 **“🖼️ 下载图片 ▾”**，选择 **1× 标准**、**2× 高清 (推荐)** 或 **3× 超高清 (打印)**，即可直接下载壁纸级 PNG 路书！
4. **备份配置**：点击 **“📤 导出 JSON”** 将路书数据备份到本地电脑，下次只需点击 **“📥 导入 JSON”** 即可一秒恢复全部数据继续编辑。

## 🚀 在线体验与本地运行

### 1. 在线使用
直接访问在线部署地址即可免费体验：

```bash
# 1. 克隆代码到本地

# 2. 进入项目目录
cd TalusTrailPlanner

# 3. 启动一个本地静态网页服务器（例如 Python 内置服务器）
python -m http.server 8080

# 4. 在浏览器中打开：http://localhost:8080
```
